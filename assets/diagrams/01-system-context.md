# 图 1：系统上下文图

**用途：** 说明系统服务谁、解决什么核心问题，以及哪些能力位于系统边界之外。  
**建议报告位置：** 第 1 章“系统范围与用户角色”。  
**状态：** 规划草图；与最终需求范围核对后再定稿。

~~~mermaid
flowchart LR
    HOST["主持人"]
    PLAYER["玩家"]
    OBSERVER["观察者（可选只读角色）"]
    SYSTEM["雾桌：多人实时协作在线虚拟桌游平台"]
    HOST -->|"创建房间、管理场景、控制权限"| SYSTEM
    PLAYER -->|"加入房间、移动获授权标记、掷骰"| SYSTEM
    OBSERVER -->|"查看获授权的场景"| SYSTEM
    ASSET["对象存储：地图图片等静态资源"]
    SYSTEM <-->|"受控的资源上传 / 下载"| ASSET
~~~

**图示说明：** 图中只表达参与者与系统边界，不展示内部数据库、网关或协调者。若最终决定不支持观察者角色，应从本图及相关需求中一并移除。
