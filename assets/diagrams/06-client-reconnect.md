# 图 6：客户端断线重连与状态恢复

**用途：** 说明客户端断线后如何恢复共享状态，不展开精细协议字段。  
**建议报告位置：** 第 8 章“容错与恢复”。

~~~mermaid
flowchart TD
    A["客户端重新连接"]
    B["重新验证身份和房间权限"]
    C{"能否安全补齐状态？"}
    D["补发可用的近期更新"]
    E["发送当前授权状态"]
    F["恢复实时协作"]

    A --> B --> C
    C -- 能 --> D --> F
    C -- 不能 --> E --> F
~~~

**关键说明：** 广播可能丢失，所以服务端需要保留恢复所需的状态或历史记录。重新同步必须重新检查权限。游标、水位和重试参数属于实现阶段。
