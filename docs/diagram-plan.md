# 设计图规划与 Codex 整合说明

> 版本：v0.2（概要设计图表基线）  
> 当前阶段：规划与设计素材准备，尚未生成最终课程设计 Word。

## 1. 图表原则

- 图应解释架构、协作流程或故障处理，不能只是装饰。
- 正文优先使用少量容易讲清楚的图，不要求把所有过程图都放进去。
- 图中的组件和消息必须与 docs/plan.md、docs/system-design.md 的概要设计一致。
- 不把详细接口字段、数据库列、租约参数或复杂事件游标协议放进正文图。
- 原始 raw/ 资料不修改；Mermaid 图源是可编辑素材，最终由 Codex 统一渲染、编号和排版。

## 3. 不作为正文必选项的图

协调者租约/epoch 的详细故障切换、复杂事件游标和周期水位对账、完整数据库实体字段、完整消息协议均属于实现级素材。除非课程评分要求明确涉及这些机制，否则不应为了展示技术复杂度而占用正文篇幅。

## 4. 统一术语

- “房间服务”负责同一房间的权威操作顺序。
- “房间标识”用于定位业务房间，不等于网络地址。
- “操作标识”用于识别同一次用户操作和重试。
- “已提交状态”表示服务端已确认保存的权威结果。
- “状态更新”表示向有权限的客户端传播已提交变化，不等于每个客户端已经收到。
- “重新同步”表示重新验证权限后补发可用更新或获取当前状态。
