# 需要用户确认的关键问题 (questions.md)

### 问题 1：选题二选一确认
老师在课堂及要求中明确限制了两个候选系统，你希望选哪一个？
- **选项 A：多人实时协作的在线设计与原型平台**（参考原型：Penpot，偏向复杂矢量画布、组件与图层协同，工业感强，微服务架构与状态同步设计极具深度）
- **选项 B：多人实时协作的在线虚拟桌游平台**（参考原型：Owlbear Rodeo，偏向虚拟桌游房间、地图Token、迷雾遮蔽与掷骰子，场景新颖有趣，网络时延与轻量协同表现亮眼）

> **分析建议**：如果想要工业级稳妥、架构图与微服务体系最丰富，推荐 **选项 A (Penpot)**；如果想要让老师耳目一新、突出轻量WebRTC低延迟与趣味场景，推荐 **选项 B (Owlbear Rodeo)**。
