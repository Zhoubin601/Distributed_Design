## 已确认事项

- **地图资源范围：** 仅从系统预置地图中选择，不纳入用户上传地图及上传流程。
- **性能与规模假设：** 保留以下全部数值，作为课程设计中的暂定目标；它们不是教师规定的硬性指标，也未经实现、压测或性能测试验证。
  - 每个房间最多 8 名同时在线成员（主持人与玩家合计；按小型房间考虑）。
  - 初始系统规模约 100 个活跃房间，用于讨论多房间分配，不代表已完成压测。
  - 同地域、正常网络条件下，从权威数据库提交到授权在线客户端收到更新的 P95 延迟目标不超过 300 ms。
  - 常规 API 从服务端收到请求到返回响应的 P95 延迟目标不超过 500 ms（不含地图文件传输）。
  - 网络恢复后，普通规模房间从连接恢复到授权状态恢复完成的目标不超过 5 秒。
- 报告必须明确将以上数值标注为**未经测试的设计假设/目标**，不得描述为已实现或已验证的性能承诺。
